# 超二收菜 · Chao2Harvester

用于 Windows / MuMu 模拟器的《超进化物语2》日常任务助手，当前版本 **0.9.67**。通过 MuMu ADB 获取游戏画面，使用 MaaFramework 进行识别，WPF 提供任务设置与运行界面。

## 下载与启动

从 [Releases](https://github.com/lonelynoodle/Chao2Harvester/releases/latest) 下载 Windows 完整发布包并解压。

**mumu打开超进化物语2，然后点击bin下面的exe启动就行**

程序为 `bin/Chao2Harvester.exe`。请保留解压后的完整目录，程序需要同级的 `runtime`、`chao2`、`resource` 和 `config.json`。打开界面后选择任务并点击开始；仅打开程序不会自动操作游戏。

从中间继续执行时，将鼠标移到已勾选的任务行，点击右侧的 ▶“从此任务开始”。本次会跳过前面的任务，按列表顺序执行该任务及后续已勾选任务，保留各任务的独立配置；不会修改模板或原有的顺序设置。

只执行一项时，将鼠标移到该任务行，点击带方框的播放按钮“仅运行本条”。无需勾选，只运行这一条任务实例，保留该条的独立设置，不执行后续任务，也不改变模板和勾选。

谜之巢穴可勾选“神灵自动释放”（默认开启），只在战斗中确认左下角为手动时切换，并确认自动状态。运行详情支持任务标题置顶收起、相邻重复消息合并及次数显示；暴走增益候选按类型着色，确认选择后突出显示。完整原始日志仍保存在运行记录中。

发布包附带 Python 和 .NET 运行环境。若 MuMu 安装位置或 ADB 端口与默认设置不同，请在设置中填写实际路径和地址。

## 功能

- 主线、异象、狩猎、浮空巨塔、永生之茧、部落冒险、凿星裂痕、黑暗森林、斗技场等日常任务。
- 庆典活动、免费奖励、饲星商店、屯屯扑满及其他任务，可按需勾选。
- 其他任务可勾选“蓝怪进化紫怪”，从怪兽信息左侧的进化树进入便捷进化。可指定只数，或持续到可用蓝怪、进化孢子任一不足。每次核对蓝怪素材、紫怪目标和材料费用，金币不足也会停止。此选项默认关闭，与饲星补料独立。
- 部落拍卖所与动态通知清理、支配核心累计捐献奖励领取，可分别开关；没有战令也会执行。可选的金币捐献使用当前账号画面左侧显示的剩余次数。
- 复制体被其他探索者击破后自动领取宝箱，免费领奖不受体力、好友币额度或挑战次数限制。
- 异象从列表顶部逐项领取和挑战，只在寻找后续目标时向下翻页；暴走旷野可勾选“重复挑战”，已有成绩也再打一轮。
- 自动领取剧情卡的免费宝箱，处理回响升级提示后返回原任务，兼容只有一行正文的短剧情。
- 屯屯扑满单项核实失败会保留交易记录并继续后续任务，未核实的购买或领取不会重复提交。
- 保存队伍选择、失败后备用队伍、资源保留和任务模板。
- 队伍设置可选战墙“忽视／进攻型／防御型”。暴走旷野默认进攻型，其他玩法默认忽视。本轮已确认的类型与任务要求一致时直接沿用，不再检查；切换成功后更新共享记录，新一轮重新确认。队伍页优先，领地入口兜底，结束后不回切。
- 领地建筑及导航名称使用固定局部区域补读，点击前再次核对；斗技场入口未确认时改走任务挑战→玩法概览。
- 秘庭与图腾详情支持“敌方阵容”标题连读、局部放大重读及图像兜底，仍核对关卡、免费布局或战令费用。
- 单项任务或子任务异常，回退到可识别页面后记录未完成并执行下一项，不重新运行整项；概览排序失败则回退到列表顺序。未知页面无法恢复时保留现场。
- 异象途中已正常处理完的商人等寻路事件会接回当前进度，重新核对列表、奖励及体力；已完成的复制体和已失败的队伍不会重打。
- 战斗等待达到原超时时间时重新核对状态，仍在战斗或结算流程就继续等待，直到本场结束；整轮时长阈值只作记录，不打断战斗和后续任务。
- 页面识别失败后的回退重试、实际结算核验、运行记录与停止操作。
- 配置窗口关闭、阵容复制和暴走增益选择支持确认原页面后的有限补点，小偏移限制在同一控件内；屏幕读取超时在旧识别任务结束后重新取图，避免重放点击。
- 前端、命令行和小工具共用进程间互斥，同一 MuMu 地址已有脚本时拒绝启动第二个实例；进程退出或异常结束后自动释放。
- 兼容显示或不显示解锁条件的位面传送门；商人领奖、战斗退出后出现传送门时，核对叉号并关闭，再继续原任务，连续受阻则跳过该任务。
- 支持手动退出结算：重新识别当前大厅、地图或关卡，按实际剩余资源继续挑战或进入下一任务；漏看的胜败记为未知，不计作失败或胜利。
- 拼二大作战、幻境巡游等小工具。

0.9.67 新增任务行续跑和单项运行、运行详情置顶和重复日志合并。狩猎按当前画面决定等待或补点，金币说明弹窗关闭后继续当前步骤，蓝怪进化改用便捷进化。支持 MuMu 上的 1.86 和 1.88 游戏版本。

## 从源码构建

源码 ZIP 不包含完整运行环境和编译后的 exe。直接使用请选择 Releases 中的完整发布包。

开发环境：Windows x64、Python 3.12、.NET 10 SDK、MuMu 模拟器。PowerShell 中执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\build-frontend.ps1 -SelfContained
.\.venv\Scripts\python.exe scripts/package_runtime.py
```

构建结果写入 `bin`，便携 Python 写入 `runtime/python`。`package_runtime.py` 要求目标目录不存在，防止混入旧依赖。使用开发虚拟环境时可不生成便携 Python，前端会回退到 `.venv`。

```powershell
.\.venv\Scripts\python.exe -m pytest
.\build-frontend.ps1 -SelfContained -Smoke
```

公开源码不包含真实账号截图和 OCR 记录。依赖私人截图的测试会明确跳过，其余测试正常执行；前端离线检查不会操作游戏。

## 目录

- `chao2/`：Python 任务、识别与工作进程。
- `frontend/`：WPF 界面源码。
- `resource/`：识别模板、OCR 模型和规则。
- `config.json`：默认设置，保留现有任务与模板配置。
- `tests/`：公开回归测试及离线模拟进程。
- `scripts/`：运行环境和发布包构建脚本。

运行时生成的 `reports/`、`debug/`、`config/`、调试截图和本机环境均不提交。反馈问题前请检查日志与截图，移除账号信息。
